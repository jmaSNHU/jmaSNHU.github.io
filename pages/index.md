Welcome to my e-Portfolio created for my computer science capstone project at Southern New Hampshire University!

### Professional Self-Assessment

During my time at SNHU, I have mastered fundamental computer science concepts on both a theoretical and practical level, including algorithms and data structures, software design and engineering, databases, web development, mobile app development, and secure programming techniques. I have also gained a strong understanding of Software Development Lifecycle (SDLC) methodologies, such as the historical basis of the waterfall model, the advantages of Agile development, and the roles and responsibilities of Scrum teams. Each of my courses at SNHU has provided hands-on experience applying these core concepts and has enabled me to build a strong portfolio that demonstrates my abilities as a computer scientist and aspiring developer. Overall, my academic experience has shaped and reinforced my career aspirations in full stack web development.

I have a strong math background in calculus, linear algebra, discrete mathematics, and statistics, which has given me a solid foundation in algorithmic problem solving, logical reasoning, and analytical skills essential to computer science. During my Applied Statistics coursework, I was introduced to Python libraries such as Pandas, NumPy, and SciPy, which continue to benefit me in my professional work. In my Data Structures courses, I learned the applications and implementations of fundamental data structures, including linked lists, stacks, queues, vectors, hash tables, and [binary search trees](https://github.com/jmaSNHU/CS-300). I also gained experience performing time complexity analysis using Big O notation to evaluate the performance of common algorithms, including widely used sorting algorithms as well as search and insert operations across various data structures. 

During my studies, I gained extensive experience with modern SDLC methodologies, particularly Agile development using the Scrum framework. The [CS 250 SDLC](https://github.com/jmaSNHU/CS-250) course deepened my understanding of effective teamwork and stakeholder communication. I learned how developers, Scrum Masters, and Product Owners collaborate within a Scrum team, as well as the purpose of key artifacts such as the product backlog, sprint backlog, and retrospectives. The course also strengthened my ability to communicate with stakeholders, both in person and virtually, by using audience appropriate technical detail to create, refine, and prioritize user stories. These skills have significantly improved my ability to collaborate within a development team and have prepared me for professional software engineering environments.

As a software engineer, I’ve learned how to build programs that are modular, maintainable, secure, and testable. In courses such as IT 145 and [CS 210](https://github.com/jmaSNHU/CS-210), I gained a strong foundation in object oriented programming—including abstraction, encapsulation, inheritance, and polymorphism—and applied these principles to write flexible, reusable code. I am well versed in test driven development and capable of implementing high coverage unit tests across multiple programming languages and testing frameworks, such as JUnit, pytest, and xUnit. I also gained experience in secure programming through courses like [CS-305](https://github.com/jmaSNHU/CS-305), developing knowledge of authentication and various authorization schemes, including role based and attribute based access control. In CS 360, I built an [Android inventory app](https://github.com/jmaSNHU/CS-360) using the Model View ViewModel (MVVM) architecture, further strengthening my mobile development skills. Additionally, I learned how to build RESTful APIs and full stack web applications, including traditional server side applications using Model View Controller (MVC) architecture and Single Page Applications that consume data from RESTful APIs.

I have extensive experience with relational database management systems such as MySQL, SQLite, and PostgreSQL, as well as NoSQL databases like MongoDB, which I worked with in [CS 340 Client Server Development](https://github.com/jmaSNHU/CS-340) and [CS 465 Full Stack Development](https://github.com/jmaSNHU/cs465-fullstack). Because I am familiar with both relational and non relational database systems, I can evaluate the trade offs between the normalized, safe, but rigid schemas of SQL databases and the speed, flexibility, and redundancy offered by NoSQL databases. I also have expertise in database security, including secure password hashing, roles, and privileges. 

### Artifact Summary

This portfolio contains three artifacts that I have selected for enhancement as demonstration of my capabilities and expertise in the areas of software design and engineering, algorithms and data structures, and databases. Each artifact originates from a different stage of my academic journey, yet they complement one another and form a unified representation of my capability to design, build, and evaluate complete computing solutions. Together, they highlight my progression from understanding foundational concepts to applying industry standard tools and practices in fully functional applications.

The first artifact is a redesigned REST API for a travel-booking web application, which showcases my software design and engineering skills by re-writing the entire backend as an ASP.NET Core Web API. I demonstrate my technical expertise of industry-standard design patterns and technologies through the use of the repository pattern, data transfer objects, unit testing, and JWT token authentication with ASP.NET Core Identity. The second artifact is B-Tree implementation in C++ using templated metaprogramming, which demonstrates my ability to apply algorithmic principles and design efficient and scalable data structures. The third artifact is a Plotly Dash web dashboard that originally used a MongoDB database. I enhanced this artifact by migrating to a SQLite database, which demonstrates my understanding of relational database systems, schema normalization and the integration of object-relational mapping with SQLAlchemy.

Together, these artifacts show that I possess a well rounded technical skillset and can work across all technical layers of a computing system, including databases, data access, algorithms and data structures, backend architecture, and client side presentation. They demonstrate my ability to use well founded and innovative techniques to build code that is extensible, modular, maintainable, and testable. These enhancements reflect my capability to design, implement, and evaluate computing solutions using algorithmic principles and sound computer science practices, while thoughtfully considering the trade offs inherent in technical design decisions. I further demonstrate my understanding of secure programming practices through the implementation of a robust, industry standard authentication and authorization model in a REST API. I further demonstrate my understanding of securing programming practices by applying industry-standard security measures to enable secure communications and authentication.
